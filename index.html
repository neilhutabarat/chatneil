Pengaturan

Atur tampilan dan pengalaman Chatneil.

Pilih tampilan terang atau gelap.

Pilih bahasa antarmuka.

Berlaku untuk foto di chat, cerita, dan foto profil. Foto asli boleh lebih besar; aplikasi mengompresnya otomatis sesuai kualitas pilihan.

Broadcast catatan rilis (Owner)

Hanya akun owner yang dapat menerbitkan catatan. Broadcast juga tampil melalui Dynamic Island.

Memuat catatan rilis...

Chatneil v1.0.61

  • Header percakapan lengkap: menampilkan nama pengguna, plakat BASIC/PRO, lencana verifikasi, titik & status online, lokasi akun, serta jarak real-time.
  • Penyesuaian latar pesan: latar gelembung obrolan dibuat abu-abu lembut (soft gray) agar tidak silau di mata.

Chatneil v1.0.60

  • Fitur Hapus Pesan & Batal Kirim (Tarik Pesan) ala WhatsApp: opsi "Batal Kirim (Tarik Pesan)" untuk menarik pesan dari semua orang (≤ 1 jam) dan "Hapus untuk Saya" untuk menyembunyikan pesan di perangkat sendiri.
  • Fitur Kirim Multifoto hingga maksimal 10 foto sekaligus dengan pratinjau thumbnail, opsi hapus foto per item sebelum dikirim, dan penambahan foto bertahap.
  • Tampilan album/kolase foto ala WhatsApp di gelembung obrolan (1, 2, 3, 4, dan 5+ foto dengan overlay +N) serta Lightbox Viewer layar penuh dengan navigasi panah dan gestur sentuh.

Chatneil v1.0.59

  • Penataan ulang layout menu Owner Control menjadi 2 kolom/baris yang ringkas dan hemat ruang.
  • Penyusunan urutan fitur: Broadcast Dynamic Island, Owner Control (User Gallery), Permission Manager, Lokasi Akun, Moderasi Akun, Verifikasi Target, dan Ubah Username.
  • Mempertahankan seluruh fungsi, validasi keamanan, dan listener Firebase agar berjalan normal.

Chatneil v1.0.38

  • Perbaikan ekspresi validasi tanda terima pesan pada Firebase Rules agar status delivered, read, dan updatedAt divalidasi secara eksplisit.
  • Mempertahankan jalur tanda terima terpisah untuk status terkirim, sampai, dan dibaca serta listener indikator mengetik.
  • Fix some bugs dan optimalisasi validasi status chat.

Chatneil v1.0.34

  • Perbaikan status notifikasi: saat pusat notifikasi dibuka, notifikasi yang ada ditandai telah dibaca dan badge lonceng diperbarui.
  • Perbaikan simpan profil dan foto dengan pembaruan field secara terarah agar sesuai dengan Firebase Rules.
  • Fix some bugs: mengurangi kegagalan izin pada pembaruan profil dan status baca notifikasi.
  • Optimalisasi proses penyimpanan agar pembaruan profil dilakukan secara konsisten dan terukur.

Chatneil v1.0.34

Notifikasi otomatis ditandai dibaca dan perbaikan simpan profil

  • Saat pusat notifikasi dibuka, notifikasi yang ada langsung ditandai sudah dibaca; badge angka di lonceng menghilang setelah status terbaca tersimpan.
  • Fix some bugs: pembaruan status baca notifikasi disinkronkan ke Firebase untuk kategori umum dan sistem.
  • Perbaikan penyimpanan profil dan foto dengan penulisan terpisah agar satu jalur yang ditolak tidak membatalkan semua perubahan.
  • Optimalisasi pesan kesalahan saat Firebase Rules menolak perubahan profil atau foto.

Chatneil v1.0.32

Banner profil pengirim pesan dengan efek kaca hitam

  • Banner untuk membuka profil pengirim pada halaman percakapan kini memakai latar hitam transparan dengan efek glass dan bingkai tipis.
  • Fix some bugs: mengurangi tampilan putih terang yang mengganggu keterbacaan pada mode gelap.
  • Optimalisasi kontras, blur, dan bayangan banner tanpa mengubah fungsi tombol profil atau tombol kembali.

Chatneil v1.0.31

Perbaikan paksa mode jam saja selama pemuatan cuaca

  • Mode jam saja diaktifkan sejak HTML mulai dirender, sehingga teks “Memuat cuaca” tidak muncul sesaat sebelum JavaScript berjalan.
  • Setiap pergantian lokasi mengaktifkan kembali mode jam saja sebelum label cuaca diubah; data cuaca hanya ditampilkan setelah respons valid diterima.
  • Fix some bugs: mencegah status Island tertinggal atau kalah oleh pembaruan lokasi yang datang belakangan.
  • Optimalisasi sinkronisasi tampilan awal, proses pemuatan, dan hasil cuaca.

Chatneil v1.0.30

Perbaikan tampilan Dynamic Island saat cuaca dimuat

  • Informasi suhu dan kondisi cuaca disembunyikan secara langsung selama permintaan cuaca berjalan, sehingga Island ringkas hanya menampilkan jam.
  • Informasi cuaca ditampilkan kembali setelah respons cuaca valid diterima; jika permintaan gagal, Island tetap dalam mode jam saja.
  • Fix some bugs: mencegah teks placeholder “Memuat cuaca” dan “--°” terlihat selama proses pemuatan.
  • Optimalisasi sinkronisasi status visual Island dengan hasil pemuatan cuaca tanpa mengubah alur autentikasi.

Chatneil v1.0.29

Pemulihan Dynamic Island dan pembaruan lokasi

  • Dynamic Island hanya menampilkan jam saat cuaca sedang dimuat atau tidak tersedia; suhu dan kondisi kembali tampil setelah data cuaca valid diterima.
  • Ketuk Dynamic Island untuk membuka panel detail seperti sebelumnya, termasuk ketika mode jam saja sedang aktif.
  • Catatan rilis terbaru ditampilkan paling atas.
  • Fix some bugs: memperbaiki mode jam saja yang sebelumnya terus aktif setelah cuaca berhasil dimuat.
  • Optimalisasi pembaruan lokasi GPS selama aplikasi terbuka. Perangkat tetap harus memberi izin lokasi; pembaruan nyata hanya dapat dilakukan untuk pengguna yang menyetujui izin tersebut.

Chatneil v1.0.28

Dynamic Island fokus pada jam saat cuaca belum tersedia

  • Dynamic Island hanya menampilkan jam jika cuaca sedang dimuat atau tidak tersedia.
  • Tampilan jam saja dipertahankan sampai sesi aplikasi berakhir, termasuk jika permintaan cuaca selesai belakangan.
  • Fix some bugs: menyembunyikan informasi cuaca dan detail Island yang dapat tampil sebagai placeholder.
  • Optimalisasi ukuran Island agar mengecil dan berpusat pada jam saat mode jam saja aktif.

Chatneil v1.0.27

Peningkatan keterbacaan dan penyempurnaan tampilan

  • Warna teks dalam mode gelap diperjelas menjadi putih agar lebih mudah dibaca di dock, daftar percakapan, kontak, profil, pengaturan, dan Owner Control.
  • Kontras teks pada kartu profil, dialog, pop-up, dan komponen antarmuka lainnya ditingkatkan.
  • Ikon dan label dock diperjelas, dengan penanda tab aktif tetap mudah dikenali.
  • Fix some bugs: memperbaiki pewarisan warna teks yang membuat sejumlah tulisan terlalu gelap.
  • Optimalisasi aturan tema gelap agar warna teks lebih konsisten pada berbagai halaman.
